# 一键复制粘贴工具 V3

> Windows 剪贴板效率工具 —— 分散在各处的文字，先全部存起来，最后一次性贴出去

## 这是什么

日常干活常遇到这种情况：要在一个地方填好几段内容，而这些内容散落在不同文件、不同网页里。

普通复制只能记住最后一次。你只能复制一段、切过去贴、再切回来复制下一段……来来回回折腾十几遍。

这个工具帮你**先把它们全部暂存起来，最后一次性贴完**。

## 怎么用（三步）

1. 在第一段文字上按 `Ctrl+C`，再按一下 **`F5`** —— 存进第 1 条
2. 换下一段，`Ctrl+C`，再按 **`F5`** —— 存进第 2 条
3. 想存多少条就存多少条，最后把光标点到要粘贴的地方，按 **`F10`** —— 全部按顺序贴出来

存进去的内容可以在记录窗口里随时查看、调整顺序、删除某一条。

## 主要功能

### 多段记录

- 把多处内容攒成一个列表，最后一次性贴出
- 每条记录可**上移 / 下移 / 置顶 / 置底**，想改顺序就改
- 可**锁定**某条，粘贴时不消耗它
- 粘贴后自动删除已贴的那条（可关闭），也能选择只贴不改

### 收藏夹

把经常要用的短句存起来，随时调用，不用每次先去别处复制一遍。

- **双击即贴** —— 立刻贴到光标处，不进记录队列
- **专属快捷键** —— 给常用的一条设个键（`Ctrl+Alt+1~9` 或空闲的 `F` 键），在任何地方按下就自动贴出
- **别名** —— 列表里显示短别名，长内容不再挤成一团
- **文件夹分类、搜索、排序** —— 收藏多了也找得到

### 其他

- 所有热键都能改，撞键了换个就行
- 托盘图标单击 / 双击的动作可以自己指定
- 配置与收藏**一键备份 / 还原 / 恢复出厂设置**
- 复制、粘贴时屏幕上会有轻提示，不用猜有没有成功

## 默认快捷键

| 按键 | 作用 |
|------|------|
| `F5` | 多次复制（记录当前剪贴板内容） |
| `F4` | 多次剪切（记录后清空剪贴板） |
| `F10` | 多次粘贴（按顺序全部贴出） |
| `F11` | 清空记录 |
| `F12` | 删除最后一条 |
| `F6` | 打开记录管理窗口 |

> 这些都能在**设置**里改成顺手的键。如果哪个键和你其他软件冲突了，换一个即可。

## 常见问题

**按 F5 提示「剪贴板为空」**

先选中文字按 `Ctrl+C` 复制，再按 F5。本工具读取的是剪贴板里的内容。

**提示「剪贴板被占用」**

有其他程序正在操作剪贴板（某些剪贴板管理软件、远程桌面工具）。稍等片刻再试。

**提示「剪贴板里不是文本」**

你复制的是图片或文件。本工具只处理文字。

**按热键没反应**

`F4` / `F5` 等可能被别的软件占用了。打开设置换一个键即可。

**双击收藏条目后没贴上**

软件会先把自己隐藏约半秒，把焦点还给你原来的窗口，然后再贴。稍等一下就好。如果仍然没反应，看下屏幕上有没有「已粘贴：…」的提示。

**托盘图标单击要慢半拍**

如果你启用了「双击动作」，单击就需要等约 0.3 秒来确认不是双击。不需要双击的话，在设置里把它关掉，单击就是即时的。

## 数据存在哪

软件是绿色版，配置和数据都在**程序所在目录**下：

| 文件 | 内容 |
|------|------|
| `config.json` | 设置（热键、延时等） |
| `favorites.json` | 收藏夹内容 |

设置窗口里有**一键备份 / 从备份还原 / 恢复出厂设置**，换电脑时可以直接把配置带过去。

> 把软件拷给别人之前，记得点一次「恢复出厂设置」，并删掉 `backups` 目录 ——
> 备份包里装的是你自己的数据。只发 exe 文件则不会有这个问题。
